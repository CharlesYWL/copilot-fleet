Connected / healthy delivery

The next batch does not wait for the previous ACK

A representative pair of overlapping batches. Time runs downward; spacing is not a latency measurement. Other workers can use the same bounded window.

Backpressure, not unlimited buffering. At most 128 live batches / 8 MiB are in flight. A larger individual event travels alone. When the window fills, additional output stays in the durable journal until capacity returns.

The chat renderer is unchanged. Host publishes to its own UI and subscribed Node views. The Node loads a conversation's transcript and subscription only when you open it; native Copilot history discovery waits until expanded.

Disconnected / local continuation and recovery

Keep talking locally. Reconcile before Host sends new work.

For an already-running, granted non-lead worker. The Node console records the local operation before invoking it; Host receives the resulting history after the connection returns.

Offline does not mean fully disconnected from everything. The model provider must remain reachable; Host-backed tools are unavailable. Permission approvals stay Host-only. Leads and resume require Host.

Local chat uses the same running worker. Busy workers can queue local prompts. Uncertain prompts are not automatically repeated; queued Host prompts affected by local intervention need confirmation. Safety stops and permission resolution are not ordinary queued work.
